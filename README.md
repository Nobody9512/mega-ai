# MEGA-AI

AI-powered data transformation tool.

## Installation

```bash
pip install mega-ai
```

## Quick Start

```bash
# Initialize configuration
mega-ai init

# Run a transformation task
mega-ai run "product titlelarni title case qil"

# Preview changes
mega-ai worker <uuid> --dry-run

# Execute changes
mega-ai worker <uuid>
```
